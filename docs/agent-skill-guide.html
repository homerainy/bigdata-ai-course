AI 智能体的「能力插件」系统 · 5 段话讲清核心

1️⃣ 一句话理解 Skill

Skill（技能） = 一个告诉 AI 怎么干某件事的指令包。
它不是代码工具，而是一份「专业操作手册」。
想象一下：你雇了一个万能助理，给他一份《财务报销流程手册》，他就懂怎么帮你报销——这就是 Skill。

2️⃣ Skill 长什么样？

标准结构（一个文件夹 + 一个 SKILL.md）：

# my-finance-skill/ ├── SKILL.md # 必填：技能说明书（核心） ├── scripts/ # 可选：辅助脚本 │ └── analyze.py ├── references/ # 可选：参考资料 └── assets/ # 可选：图标/模板等

3️⃣ SKILL.md 的关键三段

  • 📌 YAML 元信息（最顶部）：name + description，决定 AI 何时调用它
  • 📋 触发词：用户说什么关键词时会激活，比如「翻译」「查询天气」
  • 📖 操作指令：明确告诉 AI 一步步怎么做、输出什么格式

4️⃣ Skill vs 普通插件 vs Tool

Skill

  • 📄 主要是提示词
  • 🧠 教 AI 怎么做
  • ⚡ 加载即生效

普通插件/Tool

  • 🔧 主要是代码能力
  • 🛠 给 AI 新工具
  • 🐢 需要逐次调用

5️⃣ 实战场景（你能马上用上的）

  • 📚 学习「日语五十音速查 skill」：问「ま行的假名」秒答
  • 💼 工作「周报生成 skill」：告诉它本周事项，自动输出周报模板
  • 💻 开发「代码审查 skill」：给它 PR diff，按团队规范出审查意见
  • 🎓 课程「刷题 skill」：就是你之前做的 5 关递进刷题程序
🎯 一句话总结：Skill = 把「你的经验 / 流程 / 偏好」沉淀下来，下次直接复用，AI 不用每次重新学。
