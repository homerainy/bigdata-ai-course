# 概念学习资料生成器（Concept Learning Generator）

用于把《大数据与人工智能》课程里的抽象概念，转化为一份可自学、可检验的学习资料。核心目标是让学习者从"背定义"升级为"真理解"。

## 适用概念范围

覆盖大数据与人工智能课程的核心主题，常见触发词示例：

- **大数据基础**：大数据、分布式计算、Hadoop、HDFS、MapReduce、Spark、数据仓库、ETL、数据湖
- **机器学习**：监督学习、无监督学习、过拟合/欠拟合、特征工程、模型评估、交叉验证、梯度下降
- **深度学习**：神经网络、激活函数、卷积神经网络 CNN、循环神经网络 RNN、Transformer、注意力机制、反向传播
- **AI 应用**：自然语言处理 NLP、计算机视觉 CV、大语言模型 LLM、提示词工程、AI Agent
- **其他**：云计算、虚拟化、流式计算、批处理、推荐系统

任何课程中提到的名词都适用，不必局限于上表。

## 输入

用户给出的一个概念或术语，例如：

- "MapReduce"
- "什么是过拟合？"
- "帮我学懂 Transformer"
- "梯度下降怎么理解？"

## 输出格式

为指定概念生成一篇结构化学习资料，固定使用以下 **6 个部分**，每部分都有明确要求：

### 1. 一句话定义

用 1 句话（最好 30 字以内）说清楚它是什么。必须让零基础的人能秒懂，禁止堆术语。

### 2. 核心直觉 / 为什么需要它

回答三个问题：

- 没有它之前，人们是怎么做的？（痛点）
- 它解决了什么根本问题？
- 它的核心思想用一句话怎么概括？

### 3. 生活化类比

用一个贴近日常的类比来解释（快递分拣、食堂排队、图书管理员、点外卖等），帮助建立直觉。类比要与真实机制对应，并明确指出"类比中哪个部分对应哪个机制"。

### 4. 工作机制（逐步拆解）

把概念拆成 3-6 个步骤，每一步用大白话 + 必要的专业术语标注。涉及流程/架构时，可用文字分步说明或简单示意图（text-diagram）。

### 5. 代码示例

提供一段可直接运行的最小 Python 示例（≤30 行），演示该概念。如果该概念难以用代码演示，就给出一个个可操作的最小验证思路。

- 代码要有注释，重点行标注"这句在演示 XXX"
- 示例用 Python 3.12 语法，避免复杂依赖（优先标准库或最常用的 numpy）

### 6. 自测练习（3 个）

给 3 道渐进式题目检验理解：

- 第 1 题：概念识记（是什么）
- 第 2 题：机制理解（为什么 / 怎么工作）
- 第 3 题：应用判断（怎么用 / 什么场景该用它）

每道题给出参考答案和一句话解析。

## 输出示例（以"MapReduce"为例）

### 1. 一句话定义

MapReduce 是一种把大任务拆成许多小任务并行处理，再把结果合并的计算模式。

### 2. 核心直觉 / 为什么需要它

- **没有它之前**：一台机器处理海量数据，速度极慢甚至跑不动。
- **它解决了什么问题**：让大量普通机器一起干活，分担计算压力。
- **核心思想**：分而治之，先拆分（Map）、再汇总（Reduce）。

### 3. 生活化类比

像学校运动会后统计各班总分：

- **Map**：每个班先自己统计自己班的分数（并行进行）。
- **Reduce**：汇总所有班的分数，排出全校名次。
- 对应关系：每个班 = 一台机器；各班小计 = Map 输出；全校总分 = Reduce 结果。

### 4. 工作机制

1. **输入分片**：把大数据文件切成多块。
2. **Map 阶段**：每台机器读取自己那块数据，输出 `<key, value>` 对。
3. **Shuffle 阶段**：把相同 key 的数据发到同一台机器。
4. **Reduce 阶段**：对相同 key 的 value 做聚合计算。
5. **输出结果**：把 Reduce 结果写入文件系统。

### 5. 代码示例

```python
from collections import Counter

# 模拟 MapReduce：统计每个单词出现次数
texts = ["apple banana apple", "banana cherry apple"]

# Map：每段文本各自统计
mapped = [Counter(t.split()) for t in texts]

# Reduce：合并统计结果
total = Counter()
for m in mapped:
    total.update(m)

print(total)  # Counter({'apple': 3, 'banana': 2, 'cherry': 1})
```

### 6. 自测练习

1. **MapReduce 中的 Map 主要负责什么？**
   - 参考答案：把输入数据拆分成 key-value 对并做初步处理。

2. **Shuffle 阶段的作用是什么？**
   - 参考答案：把相同 key 的数据集中到一起，为 Reduce 做准备。

3. **以下哪个场景最适合用 MapReduce？**
   - A. 单人电脑处理一张 Excel 表
   - B. 1000 台服务器共同处理 10TB 日志
   - 参考答案：B

## 约束

- 每个概念都必须完整输出 6 个部分，不可省略。
- 禁止使用未解释的专业术语连环堆砌；每出现一个新术语，必须在前文或括号中给出 1 句话解释。
- 类比必须具体、可感知，不能是抽象比喻。
- 代码示例必须能直接运行或只需标准库即可运行。
